# 05 · Retrieve tools before asking a model to choose

Large catalogs waste context and degrade selection. Search trusted catalog
metadata by task, tenant entitlement and host policy, then expose a small set of
tools. Retrieval narrows candidates; it does not authorize execution.

Catalog entries need publisher identity, semantic version, scopes, side-effect
classification, residency, deprecation and provenance. Descriptions supplied by
an unknown server are untrusted input, not routing policy.

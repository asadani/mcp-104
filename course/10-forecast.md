# 10 · A bounded forecast

**Current:** stateless requests, durable task patterns, plan entitlements,
gateways, tool catalog search and model-backed tools can all be built today.

**Likely:** enterprise gateways, verified catalogs, per-tool metering, priority
classes, policy-aware retrieval and stronger route telemetry will mature as
agent traffic grows.

**Speculative:** broad automatic substitution across competing products and
many near-identical fast/slow servers. Different semantics, delegated auth and
side effects make this much harder than model routing.

Track these as hypotheses with measurable triggers: request volume, cost per
successful workflow, p95 latency, selection error rate and support incidents.
